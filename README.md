# Portfólio de Análise de Dados – TI e Suporte Técnico

Este repositório apresenta projetos de análise de dados aplicados a ambientes de Tecnologia da Informação e Suporte Técnico.

## Objetivo
Demonstrar habilidades em análise de dados, organização da informação e geração de insights a partir de dados operacionais de TI.

## Tecnologias Utilizadas
- Power BI
- SQL / MySQL
- Excel / CSV
- GitHub

## Projeto 1 – Dashboard de Chamados de Suporte
Análise de chamados técnicos com foco em:
- Tipos de incidentes
- Volume de chamados por período
- Tempo médio de resolução
- Desempenho por técnico

## Projeto 2 – Análise SQL
Consultas SQL para análise de dados operacionais, utilizando filtros, agregações e JOINs.
